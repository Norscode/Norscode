# Samla testløpar- og HTTP-rettingar

PR #270 tek med dei eksisterande rettingane frå #272 (`623cf554`) og #271
(`2e494e13`) utan å flette til main. Dei rettar to observerte main-feil:

- CI-køyring `40237806267`: slow Linux shard 0 avslutta med GC-heap full, exit 199.
  Test-NCB-en blir no klargjord i ein kortliva barneprosess.
- Selvstendighet-køyring `40237806109`: `test_apptenar_integrasjon` feila etter
  keep-alive-sekvensen. Lukking og 408 får romslegare, framleis avgrensa fristar.

## Lokal verifikasjon

Samla køyring gjennom den endra `tools/nc_test.no` bestod 8/8, utan hoppa testar,
både med den committa macOS ARM64-seeden og Linux ARM64-seeden i Ubuntu 24.04:

```
test_nc_test_forbered_barn.no
test_nc_test_oppdaging.no
test_nc_test_manifest_completeness.no
test_nc_test_parallel_contract.no
test_nc_test_skip_policy.no
test_apptenar_integrasjon.no
test_l5b_raw_bundler_metadata_filter.no
test_selfhost_seed_bundle_manifest.no
```

Begge brukte `NORSCODE_VM_FAST=1`, `NC_TEST_VM_FAST=1`, `NC_TEST_ALL=1`,
`NC_SLOW_TESTS=1`, `TEST_TIMEOUT=600` og ei eksplisitt `NC_TEST_LIST_FILE` med
lista over. Linux hadde eigen checkout med Linux-seeden som `dist/norscode_native`;
macOS hadde macOS-seeden. Barn som brukar `bin/nc` eller `dist/norscode_native`
må få ein binær for riktig plattform, ikkje berre rett `NORSCODE_NATIVE_BIN`.

Feature-check bestod for testløparen, barneverktøyet og dei to endra testane.
`git diff --check` var rein. Dette er målretta integrasjonstest, ikkje prov på at
heile slow-suiten eller minneprofilen er ferdig verifisert. Full GitHub CI på den
nye PR-tippen er framleis påkravd før innfletting.
